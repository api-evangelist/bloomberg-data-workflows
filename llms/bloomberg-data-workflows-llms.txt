# Bloomberg Data Workflows

> Bloomberg's programmatic data-workflow surface for institutional clients: the Data License API
> (batch and per-security delivery of reference, pricing, regulatory and alternative data over a
> JWT-authenticated REST/hypermedia endpoint, SFTP, or native cloud delivery) and the Server API
> (SAPI), the shared-server deployment of BLPAPI for real-time and historical market data. Both
> require an active Bloomberg Professional or Enterprise agreement. No OpenAPI, AsyncAPI, GraphQL
> SDL or MCP server is published for either API; the reference documentation sits behind the
> DATA <GO> customer portal.

Generated by API Evangelist from verified probes on 2026-08-27. Bloomberg does not publish an
llms.txt; this file is generated, not harvested.

## APIs

- [Bloomberg Data License API](https://professional.bloomberg.com/products/data/data-license/): Batch and per-security delivery of Bloomberg reference, pricing, regulatory and alternative data. REST/hypermedia entry point at https://api.bloomberg.com/eap/ — every request must carry a signed JWT (RFC 7519). Also delivered over SFTP and natively into major cloud providers.
- [Bloomberg Server API (SAPI)](https://professional.bloomberg.com/products/data/data-connectivity/server-api/): The shared-server deployment of BLPAPI. Not HTTP — clients open a TCP session with the BLPAPI SDK against the customer's own SAPI host, and receive real-time subscription and historical request/response data.

- [BLPAPI Core Developer Guide (PDF, 2017)](https://data.bloomberglp.com/professional/sites/10/2017/03/BLPAPI-Core-Developer-Guide.pdf): The conceptual guide to sessions, services, schemas, events and messages. Still the only narrative documentation on offer.
- [BLPAPI Core User Guide (PDF, 2017)](https://data.bloomberglp.com/professional/sites/10/2017/03/BLPAPI-Core-User-Guide.pdf)
- [Release Notes](https://professional.bloomberg.com/support/documentation/release-notes/): Dated release notes for the Bloomberg Terminal and Office Tools. There is no changelog for the Data License REST API, the Server API or the BLPAPI SDK.
- [DATA &lt;GO&gt; portal](https://data.bloomberg.com/): Self-service enterprise data portal for browsing, testing and customizing datasets. Login required; the API reference lives here.

## Authentication

- Data License REST API: per-request signed JWT in a request header. No token endpoint, no API key, no client-credentials flow, no public sandbox credential. An anonymous call to https://api.bloomberg.com/eap/catalogs/ returns 401 `unauthorized_client` / "No definition of jwt found in header or query string."
- BLPAPI / SAPI: Terminal entitlements (Desktop API) or customer-provisioned credentials against the customer's own SAPI or B-PIPE host. No token of any kind.
- Bloomberg.com web identity (a separate surface, not the data APIs): OpenID Connect at https://www.bloomberg.com/.well-known/openid-configuration — authorization_code + refresh_token, mandatory PKCE S256, scopes `openid`, `user`, `entitlements`.

## Not available

- No OpenAPI or Swagger document is published on any Bloomberg host.
- No AsyncAPI, no GraphQL SDL, no WSDL, no .proto.
- No first-party MCP server and no A2A agent card.
- No public pricing, no published rate limits, no status page, no deprecation policy, no SLA.
- No public sandbox or trial credential.
